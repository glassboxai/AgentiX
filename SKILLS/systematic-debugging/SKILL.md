# Systematic Debugging

Capture the exact trigger and bounded redacted diagnostics. Reproduce with a minimal trusted fixture outside generated_tools; distinguish product, checker, model, environment and harness failures. Trace the first incorrect boundary, test one concrete hypothesis and retain a failing regression. Explain cause, affected files and proposed correction; obtain validation outside the approved block. Make the smallest causal fix, rerun the reproducer and affected integrations, then document the incident. Do not weaken independent expectations, add sleeps to hide races, restart live apps or execute generated code on the host. Stop repeated guesses; report missing evidence and limitations.

AGENTS.md supplies shared exclusions, authorization and English-documentation rules; do not duplicate or override them.
