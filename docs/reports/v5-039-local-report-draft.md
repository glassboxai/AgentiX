The tools included a basic calculator, a vowel counter, a word counter based on whitespace, and a seeded bounded random number generator. Initial model outputs had inconsistencies in specifications, arithmetic errors, incorrect word counts, and invalid JSON and API metadata. These were corrected through human review.

Each new tool’s public function was required to match its tool name, with Annotated parameter and return descriptions enforced by static checks. Reusing the GUI for all four tools produced correct results without requiring approval or rerunning old unit tests.
