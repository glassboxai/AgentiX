The new regression failed before correction; configure_process now sets False. This enforces startup policy and avoids the analytics path involved in the earlier startup failure; it does not prove all framework initialization bugs absent.
- **Known issues and regression register**: UI-013: the missing project link was reproduced by the header regression before implementation (`reports/ui013-link-red.txt`). Link order is now tested alongside computed square corners, checkbox dimensions/colors and Space-key toggling. The external reference was inspected read-only, without saving configuration.
- **UI-012 presentation incidents (2026-10-20)**: - UI012-ERR-001 (corrected): the CSS send glyph contributed to the accessible name, preventing exact-name browser actions. Empty CSS alternative text makes it decorative while retaining Send query. The initial five browser failures and final five passes are retained.
- **Domain-only supervised review (2026-10-20)**: LIVE-USER-ERR-001/002/003/004 concern temporary model proposals: an incorrect specification example, boolean/unused-tier code defects, an overconstrained error message test and malformed acceptance data. Each was reviewed and corrected; the original and approved evidence is retained. - **Communication block incidents (2026-10-19)**: Current status: the full approved block completed one real English supervised creation/review/acceptance/execution run with qwen3-coder:30b.
